Heat Panel

A simulated 64×32 LED board, the layout a real panel on a Raspberry Pi would show, fed by Spotify Soloist’s local WebSocket. Try the demo first, then point it at a running Soloist.

Everything on the board is real playback data: title, artist, cover art (shrunk to 32×32), position and play/pause. Title and artist sit on one line each and line up; if either is too long, both scroll sideways together. The small record is the progress meter: it turns while playing and its rim fills to the end of the song. Pick a layout above: “Cover as backdrop” dims the cover behind the names, and “Flip” alternates a names screen with a cover screen. The demo cover is made-up artwork; “My top artists” uses your real covers.

Run Soloist

export SOLOIST_API_KEY=…   # from the Spotify developer dashboard; keep it out of git
soloist --device-name "Heat Lab" --api-key "$SOLOIST_API_KEY" --ws 127.0.0.1:9090

Then pick “Heat Lab” in the Spotify app (same network) and start playing. This page only reads (get_state, get_queue); it never sends playback commands. Soloist’s socket has no authentication or TLS, so only loopback addresses are accepted here. Reach a Soloist on another machine through an SSH tunnel or Tailscale, not by exposing the port.
